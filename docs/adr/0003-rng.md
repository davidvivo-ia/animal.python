# ADR 0003 — RNG inyectado tras un Protocol

## Contexto

El BASIC original no usa aleatoriedad — el recorrido del árbol es
determinista. Pero CLAUDE.md exige RNG inyectado para habilitar
`--seed` y tests deterministas, y nosotros añadimos saludos variados,
selección de pistas y un modo `--demo` con guion.

## Decisión

- `domain.protocols.Rng` es un `Protocol` con `choice`, `random`, y
  `seed`.
- Implementación por defecto en `infrastructure.rng.StdRng(seed=None)`,
  envuelve `random.Random`.
- Todo el código que necesita aleatoriedad recibe el `Rng` como
  parámetro.

## Consecuencias

- Tests deterministas pasando un `Rng` de seed fijo.
- El modo `--demo` usa `seed=42` por defecto.
- Cero llamadas a `random.random()` global.
